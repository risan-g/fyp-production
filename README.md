## Submission Contents

- **`/app`**: Core application logic and API Route Handlers.
- **`/components`**: UI elements, Search, and Rating Sliders.
- **`/lib`**: Supabase and Spotify API utility functions.
- **`.env`**: Pre-configured with active API tokens.
- **`README.md`**: Project documentation.

### Prerequisites

- Node.js
- npm

## How to Run the Project

The project environment is pre-configured with the necessary API tokens in the included `.env` file. To initialise the project locally, please follow the steps below:

### 1. Installation

Open your terminal within this, be in the product folder and run the following command to install the required dependencies:

npm install

### 2. Execution

Launch the local development server:

npm run dev

### 3. Accessing

The application will be accessible at http://localhost:3000.
